# FreeStand × Mondelez — Joy Club Use Cases

Interactive demo of five Mondelez use cases in the FreeStand demo-hub UI:

1. **All channels → Joy Club**: one loyalty destination for every channel
2. **Loyalty strategy**: a loyalty mechanic per brand, plus a Joy Club walkthrough
3. **Receipt → UPI cashback** (Cadbury)
4. **IPL TV QR → limited drop** (Biscoff × Marvel)
5. **Creator engagement** (Cadbury Celebrations UGC)

`index.html` is a self-contained bundle served as-is by GitHub Pages.
